# One Line of Earned Pride

A single 123-character line about a mechanic whose engine finally catches and holds after three days of stubborn repair — quiet, earned pride shown through split knuckles and a gasket that seats on the second try, with no trophy, podium, or congratulation.

## The winning line

> Her knuckles split on the last bolt, the gasket seats on the second try, and after three days the engine catches and holds.

## Run

`python3 main.py`

The program asserts the line is a single line of 1–240 characters, creates `/output` if needed, writes `/output/entry.txt` (UTF-8) and prints the line.
